# Smart-home
Description

Projet réalisé dans le cadre de mon stage, consistant à développer une maquette de maison connectée avec pilotage à distance et monitoring en temps réel.

Mon travail a porté sur :

-Conception mécanique de la maquette sous SolidWorks

-Intégration de capteurs et actionneurs (température, gaz, mouvement…)

-Développement d’une application mobile Android

-Communication IoT via Firebase Realtime Database

 Fonctionnalités développées

-Ouverture / Fermeture de porte (Servo-moteur)

-Allumage / Extinction de LED

-Visualisation en temps réel :

-Température & humidité

-Gaz

-Mouvement

-Humidité du sol

-Alerte buzzer en cas de fuite de gaz

-Affichage local sur LCD

 Technologies utilisées:
 
-Mobile	Android (Java)

-IoT & Communication	ESP32, Firebase Realtime Database

-Capteurs	DHT11, MQ-2, PIR, Humidité du sol

-Actionneurs	Servo-moteur, LED, Buzzer

-Affichage	LCD 16x2

-Conception	SolidWorks

 Objectifs atteints

-Développement d’une solution domotique fonctionnelle

-Communication ESP32 ↔ Firebase ↔ Application mobile

-Gestion temps réel + alertes de sécurité

-Modélisation d’une maquette prête à fabrication
